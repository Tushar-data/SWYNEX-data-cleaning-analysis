# Customer Churn Analytics Project

## Project Overview
This project analyzes customer churn using Python and Power BI to identify important customer behavior and churn patterns.

## Dataset
The dataset was collected in Excel format and used for data cleaning, exploratory data analysis, and visualization.

## Tools & Technologies
- Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- DAX
- Power Query

## Project Workflow
Excel Dataset → Python Data Cleaning → Exploratory Data Analysis → Power BI Dashboard → Business Insights

## Python Analysis
Python was used for:
- Data cleaning
- Missing value analysis
- Duplicate value checking
- Data type checking
- Exploratory Data Analysis
- Data visualization using Matplotlib

## Power BI Dashboard
The dashboard analyzes:
- Total Customers
- Churned Customers
- Churn Rate
- Average Monthly Charges
- Churn by Contract
- Churn by Gender
- Churn by Internet Service
- Churn by Payment Method
- Total Tenure by Churn

## Key Metrics
- Total Customers: 1K
- Churned Customers: 345
- Churn Rate: 28%
- Average Monthly Charges: 77.26

## Conclusion
The project provides an interactive view of customer churn patterns and helps understand the factors associated with customer churn.
